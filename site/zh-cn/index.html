一个安静的写作空间，就在你的 AI 智能体旁边

Quillwright 是一款用于写长篇小说和长文档的桌面软件。你的书就是一个装着普通 Markdown 文件的文件夹。你已经在用的 AI 工具可以在你写作的同时处理它，而未经你同意，任何内容都不会进入你的正文。

为什么选择 Quillwright

为与 AI 合作的写作者而做，而不是让 AI 取代写作者。

i.

你的书始终属于你

没有专有格式，也没有云端。每个章节、每个人物各是一个 Markdown 文件，任何编辑器都能打开，容易备份，也可以直接用 Git 管理。

ii.

配合你在用的智能体

Claude Code、Codex，或通过 Ollama 运行的本地模型。Quillwright 理解章节和人物，智能体和你在同一个文件夹里工作。

iii.

一个小巧的软件

一个用 Rust 编写的原生程序。无需账号、无需订阅、无需 API 密钥。内置导出 Word、EPUB 和 PDF。

与智能体一起写作

智能体修改文件，由你来决定。

  • 更改即时显示当智能体新增一章或修改正在打开的章节时，侧边栏和页面会随之更新，你的位置也不会丢失。
  • 建议以差异显示，没有意外改写一段文字、续写场景，或对照世界规则检查一章。每处改动你都能看到，并决定是否接受。
  • 你的文字永远不会被覆盖原子化保存、每次写入前的检查，以及保存在项目之外的版本历史。

支持 Claude Code、Codex、Aider、Ollama 或任何命令行工具。

功能

长篇项目需要的一切，没有多余的干扰。

一张纸，而不是一个文本框

实时显示 Markdown 格式，衬线字体，居中排版。只有正在编辑的那一行才显示语法符号。

书稿侧边栏

按阅读顺序列出章节和字数，还有当前章节的大纲、人物和笔记。一键新建下一章。

专注工具

全屏专注模式、打字机滚动、淡化其他段落，以及纸张、复古和夜间三种主题。

资料就在页面旁边

PDF、图片和笔记在章节旁边打开。可以在 PDF 中搜索，并把一段文字连同出处发送给助手。

搜索整个项目

章节、人物设定、笔记和 PDF，不区分大小写和重音符号。

使用你的语言

界面支持中文、英语、葡萄牙语和西班牙语。拼写检查使用书稿的语言，并自动认识人物的名字。

自动保存与历史

停止输入片刻后自动保存。每一章的早期版本都可以比较和恢复。

离线导出

Word、EPUB、PDF、OpenDocument 和 HTML，带扉页和目录。无需安装其他软件。

看得见的进度

本章和全书的字数、阅读时间、本次写作的字数，以及可选的目标。

项目模板

从一个智能体能看懂的结构开始。

“新建项目”会创建文件夹和一份指南 AGENT.md，告诉 AI 智能体如何处理这个项目。你也可以直接打开任何现有文件夹。

小说

章节、人物设定，以及一份记录世界规则的文档。助手会据此检查连贯性。

my-novel/ ├── AGENT.md ├── world-rules.md ├── chapters/ │ └── 001-opening.md └── characters/ └── example-character.md

法律案件

文书、当事人、附有证据的事实，以及时间线。助手从不编造事实或引文。模板提供英文和葡萄牙文版本。

case/ ├── AGENT.md ├── facts.md · timeline.md · evidence.md ├── filings/ │ └── 001-complaint.md ├── parties/ └── case-files/ 法院 PDF
